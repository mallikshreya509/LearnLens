[00:00] Welcome back. Today we're going to look at how a neural network actually learns, and the short answer is that it learns by making mistakes and then reducing them, step by step.
[00:18] Let's start with the idea of a loss function. A loss function is a single number that tells us how wrong the network's predictions are. If the loss is high, the network is doing badly, and if the loss is close to zero, it's doing well.
[00:44] A common example for regression is mean squared error. You take the difference between each prediction and the true value, square it, and average those squares across all your examples. Squaring makes sure that big mistakes are punished much more than small ones.
[01:12] Now, the network has parameters, which we call weights and biases. Training means finding values for those weights and biases that make the loss as small as possible.
[01:35] Imagine you are standing on a foggy hillside and you want to reach the valley. You can't see the whole landscape, but you can feel the slope under your feet. So you take a step downhill, feel the slope again, and repeat. That is the intuition behind gradient descent.
[02:08] More formally, the gradient is a vector of partial derivatives. It tells us, for every weight, how much the loss would change if we nudged that weight slightly. The gradient points uphill, so to reduce the loss we move in the opposite direction.
[02:40] The size of each step is controlled by the learning rate. If the learning rate is too small, training is painfully slow. If it is too large, we overshoot the valley and the loss can bounce around or even blow up. Picking a good learning rate is one of the most important choices in training.
[03:15] In practice we rarely compute the gradient over the entire dataset for every step, because that is expensive. Instead we use mini-batches: we take a small random subset of the data, compute the gradient on that, and update the weights. This is called stochastic gradient descent, or SGD for short.
[03:52] One pass through the whole training set is called an epoch. We usually train for many epochs, watching the loss go down over time.
[04:15] But how do we actually calculate the gradient for a network with millions of weights? That's where backpropagation comes in. Backpropagation is an efficient way to compute all of those partial derivatives using the chain rule from calculus.
[04:48] The chain rule says that if one quantity depends on another, which depends on a third, you can multiply the rates of change along the chain. In a network, the loss depends on the output, the output depends on the last layer's weights, and so on backwards through the layers.
[05:25] So the process has two phases. First, the forward pass: we feed the input through the network, layer by layer, and compute the prediction and the loss. Second, the backward pass: we start at the loss and move backwards, computing the gradient for each layer and reusing the results from the layer after it.
[06:05] Reusing those intermediate results is what makes backpropagation fast. Without it, we would have to recompute the same quantities again and again for every single weight.
[06:30] A common problem is overfitting. This happens when the network memorizes the training data, including its noise, and then performs poorly on new data. You can spot it when the training loss keeps falling but the validation loss starts to rise.
[07:05] To fight overfitting we can use more data, simpler models, regularization such as weight decay or dropout, and early stopping, where we halt training once the validation loss stops improving.
[07:40] To summarize: a loss function measures error, gradient descent uses the gradient to reduce that error, the learning rate sets the step size, backpropagation computes the gradients efficiently with the chain rule, and we watch validation loss to avoid overfitting.
